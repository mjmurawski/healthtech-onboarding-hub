Narzędzie Specjalistyczne

🏥 Specjalista Systemów Medycznych & SRE

Narzędzie Diagnostyczne

🔍 Dekoder Stack Trace'ów i Błędów Aplikacyjnych

Wklej surowy stack trace z Java, .NET (C#) lub Delphi, lub komunikat błędu Oracle / PostgreSQL. System natychmiast zwróci kontekst biznesowy, prawdopodobną przyczynę i bezpieczne zapytanie SQL do weryfikacji stanu bazy danych.

Narzędzie SQL

🗄️ Generator Bezpiecznych Zapytań SQL

Generuj diagnostyczne zapytania SELECT z szablonów (offline), twórz bezpieczne szablony UPDATE opakowane w transakcję testową z domyślnym ROLLBACK, lub opisz problem w języku naturalnym i pozwól Gemini AI wygenerować gotowy SELECT.

Weryfikacja Powdrożeniowa & QA

📝 Tworzenie Dokumentacji i Testów PatExpert

Dedykowany Agent AI wyspecjalizowany w testach funkcjonalnych, weryfikacji powdrożeniowej i dokumentacji technicznej dla systemu PatExpert (pracownia histopatologiczna). Przekształcaj informacje o patchach i poprawkach w gotowe scenariusze testowe (Test Case), testy regresji oraz instrukcje postępowania dla I linii wsparcia.

Asystent Błyskawiczny

⚡ Szybki Konsultant IT (Programowanie / Bazy Danych / Systemy Medyczne)

Dedykowany agent AI do błyskawicznych, ultra-zwięzłych odpowiedzi technicznych. Same konkrety: gotowy kod, komendy Bash, zapytania SQL i kluczowe uwagi diagnostyczne od pierwszego zdania.

Site Reliability Engineering & Ansible

🤖 Centrum Automatyzacji SRE & Ansible

Automatyzacja, powtarzalność i stabilność dla inżynierów SRE ze wsparciem aplikacyjnym. Katalog idempotentnych playbooków i ról Ansible, hybrydowe skrypty Python + Bash, parser wyników PLAY RECAP oraz dynamiczny generator automatyzacji.

Standard Operating Procedure • PostgreSQL & Centrum

🐘 Aktualizacja Bazy PostgreSQL & Centrum (SOP)

Oficjalna, produkcyjna procedura aktualizacji bazy PostgreSQL i systemu Centrum (opracowanie: Zespół Inżynierów SRE). Krok po kroku: zero-connection check, OpenRC/systemd, trik z tabelą wersja, aktualizacja binariów, podpisywanie licencji Wine (kgp.exe), obsługa satelitów (RDP/CZA) oraz ściągawka komend terminalowych.
